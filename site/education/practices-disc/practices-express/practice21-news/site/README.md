# Практическая работа №21 — тизеры новостной ленты

Откройте `site/index.html` через локальный сервер. При загрузке страницы `prompt()` запрашивает количество карточек от 1 до 12. Некорректное значение вызывает собственную ошибку `NewsCountError`: её технический текст и описание выводятся в консоль, а пользовательское сообщение — на странице. После ошибки можно повторить ввод через встроенную форму.

Данные новостей вынесены отдельно в `assets/js/news-data.js`, оформление — в `assets/css/style.css`, сценарий — в `assets/js/app.js`. Изображения — локальные SVG-заглушки, потому что папка `images` в исходном архиве содержала только текстовый файл-подсказку.

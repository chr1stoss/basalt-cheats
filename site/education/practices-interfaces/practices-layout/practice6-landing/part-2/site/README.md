# Практикум 6.2 — KINETIK

Концептуальный интерактивный лендинг с четырёхслойной 3D-композицией, перспективой, световыми эффектами, SVG HUD, управлением сборкой/разборкой и режимом просмотра каждого слоя. Мышь меняет наклон сцены через `requestAnimationFrame`; на сенсорных устройствах — мягкое idle-движение и кнопочный режим; `prefers-reduced-motion` отключает декоративные анимации. CSS использует transform/opacity для анимаций.

Откройте `index.html` в браузере. Показатели в техническом блоке явно отмечены как демонстрационные параметры концепта, а не заявленные реальные характеристики изделия.

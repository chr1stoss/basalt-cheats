# Практическая работа №10 — магазин на нативной платформе

Откройте `site/index.html` через локальный сервер. Проект не подключает Bootstrap, CSS/JS-библиотеки или сборщики: только HTML, CSS, JavaScript и локальные SVG.

## Индивидуальный вариант

Использован номер в списке группы **N = 22**. Параметры рассчитаны по формулам методички:

| Параметр | Расчёт | Значение | Где применяется |
|---|---|---:|---|
| H | (22 × 37) mod 360 | **94°** | `--hue` |
| C | 150 + 10 × (22 mod 8) | **210 px** | `--col-min` |
| T | 22 + 2 × (22 mod 5) | **26 rem** | `@container card` |
| R | 22 mod 3 = 1 | **1.25** | `--ratio` |

Первая карточка называется **«Пивкин · Настольная лампа „Тихий свет“»**.

### Фотографии

По просьбе пользователя вместо личных фотографий добавлены четыре заметные SVG-заглушки: `assets/img/product-01.svg` — `product-04.svg`. Это именно временные заглушки, а не выполненное требование о четырёх собственных фотографиях. Перед окончательной сдачей замените их четырьмя снимками, сделанными самостоятельно, сохранив имена файлов либо обновив пути в `assets/data/products.json`.

## Что реализовано

Каталог, страница товара (`product.html?id=1`) и корзина (`cart.html`) используют один рендерер карточки. Реализованы CSS Grid, `@container`, Cascade Layers, `clamp()`, `:has()`, нативные `<dialog>` и Popover API, единая корзина в `localStorage`, мини-корзина и статусное сообщение. Карточка переключается в режим «строка» при ширине контейнера `26rem` и более; мини-корзина имеет отдельный компактный режим.

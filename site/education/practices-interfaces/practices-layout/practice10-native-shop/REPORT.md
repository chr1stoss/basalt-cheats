| Параметр | Формула | Результат |
|---|---|---:|

| C — минимальная ширина колонки | 150 + 10 × (22 mod 8) | **210 px** |

## Расчёт колонок каталога

Ширина внешнего контейнера — `min(100% - 32px, 1320px)`. Минимум одной колонки — 210px. Шаг между карточками задаётся `clamp(12px, 8px + 1vw, 24px)`. При ширине окна выше 760px включается боковая панель шириной 230px и межколоночный отступ `clamp(20px, 3vw, 48px)`.

| Окно | Доступная ширина каталога (примерно) | Gap карточек | Колонки |
|---:|---:|---:|---:|
| 375px | 343px | 12px | **1** |
| 768px | 483px | 15.7px | **2** |
| 1280px | 980px | 20.8px | **4** |

Ориентировочные пороги добавления колонок при текущей структуре: 2-я — около **465px**, 3-я — около **692px** в режиме без боковой панели; при переходе через 760px панель фильтров появляется снова и ширина каталога уменьшается. В широком режиме 3-я колонка появляется примерно при **956px**, 4-я — при **1198px**. Значения приблизительные, поскольку `gap` плавно зависит от viewport; подтвердите фактические размеры в DevTools.

## Карта миграции №9 → №10

| Задача | Было в Bootstrap (№9) | Стало на платформе (№10) | Смысл изменения |
|---|---|---|---|
| Колонки каталога | `.row-cols-*` | `repeat(auto-fill, minmax())` | Колонки определяются доступной шириной контейнера. |
| Карточка | `.card`, утилиты сетки | Grid + `@container` | Компонент реагирует на ширину родителя. |
| Быстрый просмотр | `.modal` | `<dialog>` + `showModal()` | Нативный фокус, Esc и backdrop. |
| Мини-корзина | dropdown/offcanvas | Popover API | Открытие и закрытие без JS-библиотеки. |
| Уведомление | Toast Bootstrap | `<output role="status">` | Сообщение доступно скринридеру. |
| Фильтры | `.offcanvas-lg` | собственная панель | Поведение управляется проектом. |

## Четыре ловушки для демонстрации

1. Откройте `dialog` через `showModal()`; сравните с атрибутом `open` и методом `show()` — у них нет модального backdrop/ловушки фокуса.
2. Откройте мини-корзину Popover API и проверьте закрытие кликом вне блока; поповер попадает в top layer, поэтому его расположение задано самостоятельно.
3. Выберите фильтр и проверьте `.filters:has(:checked)`; состояние `:has()` исчезает после перезагрузки, если его отдельно не сохранять.
4. Измените ширину `.slot` при неизменной ширине окна; карточка перестраивается по `@container` при достижении 26rem, а не по `@media`.

## Проверка структуры и бюджета

- Внешние CSS/JS-библиотеки и Bootstrap не подключаются.
- `main.css`: **12 781 байт** (≈12.8 KB), лимит — 20 KB.
- `app.js`: **5 819 байт** (≈5.8 KB), лимит — 6 KB.
- Для карточки нет `@media` по ширине окна; режимы «столбец», «строка» и компактный режим мини-корзины задаются `@container`.
- В таблице стилей нет `!important`; используются два ширинных `@media` для общей раскладки и отдельный `prefers-reduced-motion`.
- JavaScript прошёл проверку синтаксиса Node.js; CSS разобран без синтаксических ошибок, JSON данных товаров и локальные пути к изображениям проверены.
- Автоматический браузерный прогон в рабочей среде был заблокирован политикой доступа к localhost, поэтому визуальные/интерактивные проверки следует повторить локально через Live Server.

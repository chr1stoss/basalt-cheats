# Практическая работа №9 — каталог Bootstrap

Откройте `site/index.html` через локальный сервер (например, Live Server). Bootstrap 5.3 и Bootstrap Icons подключаются по CDN; остальные файлы и изображения находятся в проекте.

Реализовано: вложенная сетка `col-lg-3` / `col-lg-9`, адаптивная панель `offcanvas-lg`, карточки `row-cols-2` / `row-cols-md-3`, промо-карусель, хлебные крошки, фильтрация, сортировка, пагинация, единый modal быстрого просмотра и toast корзины.

В каталоге использованы оригинальные локальные SVG-иллюстрации вместо фотографий из Figma. Это обеспечивает корректную загрузку без сторонних фотохостингов.

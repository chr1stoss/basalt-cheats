# Практическая работа № 8 — Интерфейсы
## Вёрстка корпоративного лендинга «Positivus» на Bootstrap 5

Учебный проект по методическому руководству «Практикум №8». Реализованы адаптивная страница, кастомизация Bootstrap через CSS-переменные, мобильное меню Offcanvas, аккордеон этапов работы и клиентская валидация форм.

## Состав

- `index.html` — семантическая HTML5-разметка страницы.
- `css/custom-theme.css` — дизайн-токены Bootstrap: лаймовый `#B9FF66`, тёмный `#191A23`, серый `#F3F3F3`, радиусы и стили кнопки.
- `css/main.css` — адаптивная сетка, карточки услуг, блоки команды, форма и оформление.
- `js/app.js` — управление мобильным меню, аккордеоном и валидацией форм.
- `assets/` — каталог для локальных графических материалов; ключевые декоративные иллюстрации сделаны CSS-элементами и SVG прямо в HTML.

## Запуск

Откройте `index.html` в современном браузере. Bootstrap 5.3.3, Bootstrap Icons и шрифт Space Grotesk загружаются с CDN, поэтому для полного оформления требуется подключение к интернету.

## Реализованные требования

- 12-колоночная сетка Bootstrap (`container`, `row`, `col-*`), брейкпоинты для Desktop, Tablet и Mobile.
- На широком экране первый экран расположен в две колонки; на планшетах и смартфонах контент складывается вертикально.
- Карточки услуг перестраиваются в две колонки от `md` и в одну колонку на мобильных устройствах.
- Корпоративная палитра и радиусы переопределяются через CSS Custom Properties Bootstrap, без прикладного `!important`.
- Мобильная навигация на Bootstrap Offcanvas.
- Аккордеон процесса на Bootstrap Accordion с `data-bs-parent`.
- Клиентская проверка обязательных полей формы, email, согласия и текста сообщения.
- Подписи для элементов формы, доступные названия интерактивных кнопок, клавиатурная навигация и учёт `prefers-reduced-motion`.
- Нет горизонтального аварийного скрытия содержимого через `overflow-x: hidden` у `body`.

## Примечание

Формы демонстрационные: данные не отправляются на сервер и не сохраняются. Ссылки на социальные профили и юридические документы служат макетными переходами. Названия, имена и показатели на странице — учебные примеры.

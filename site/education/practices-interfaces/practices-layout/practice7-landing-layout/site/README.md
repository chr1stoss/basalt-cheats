# Практическая работа 7 — MOTTO

Адаптивный лендинг архитектурной студии на HTML/CSS/JS без сборщика. Реализованы блоки «О студии», проекты с фильтрацией, процесс и контактная форма-демо; навигация-бургер на мобильных, фиксированная шапка с состоянием при прокрутке, CSS Grid, `clamp()`, aspect-ratio, hover/focus-visible и `prefers-reduced-motion`.

Откройте `index.html` в браузере. Google Fonts подключён как прогрессивное улучшение: при отсутствии интернета используются системные шрифты. Изображения в папке `assets/img/projects/` — локальные демонстрационные фото. Форма не отправляет данные на сервер и показывает локальное подтверждение. Макет реализован по требованиям методички; точное совпадение с Figma не заявляется, так как исходный файл Figma не был экспортирован в PNG/PDF для сравнения.
